# Manuals - UAT 20.27

The Ham-Rx CPS User Guide is an original application guide, versioned with UAT 20.27. It contains actual UAT screenshots using synthetic demonstration channels. The eight-page PDF was rendered and visually checked before publication. No physical-radio write was performed to make the guide.

The original `Baofeng_MINI-5_User_Manual_EN_V1.0_20260920.pdf` was located locally, but is deliberately not included. K4RJM directed that it stay pending redistribution permission. Its selector entry is disabled and labeled accordingly. Do not replace it with an arbitrary PDF or enable the entry until permission is documented.

The viewer keeps a single iframe and unchanged source on expansion, return and close/reopen. Reading-position retention depends on the browser PDF engine; no cross-origin viewer internals are accessed. A separate-tab link is provided for browsers without embedded viewing.

The in-app browser did not paint its native PDF plug-in. A local Mozilla PDF.js 5.6.205 renderer now supplies page navigation, fit/zoom, accessible page text and a download link. The separate-tab control opens that same PDF renderer. The original PDF remains directly downloadable. See ../../vendor/pdfjs/LICENSE.
